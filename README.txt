SAI WEBSITE — VERSION 0.1

This folder contains a static website:
- index.html: the website
- manifest.webmanifest: installable web app metadata

To preview:
Open index.html in a browser.

To publish:
Upload the contents of this folder to a static website host that permits your account and age requirements. A public URL is not created automatically by this ZIP.

Important:
This is a demo website. Replies are local sample responses, not real AI-generated answers. No chat messages are sent to a server.
